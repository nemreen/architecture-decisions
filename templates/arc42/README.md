# arc42 template

Copy this folder into a project when you publish a full architecture package:

```text
cp -R templates/arc42 projects/<slug>/arc42
```

Then fill sections one at a time. Diagrams live in that project's `diagrams/`. Decisions live in that project's `adr/` and are linked from section 09.
